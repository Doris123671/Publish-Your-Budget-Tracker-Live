# Budget Tracker 💰

A beautiful, responsive budget tracking dashboard designed to help you manage your expenses with ease. This project demonstrates modern UI/UX design patterns with a clean, professional interface.

## 📋 About This Project

**Budget Tracker** is a visually complete expense management dashboard built with vanilla HTML, CSS, and JavaScript. It showcases a professional dashboard interface with:

- **Beautiful, responsive design** that works on desktop, tablet, and mobile devices
- **Interactive components** including a kanban-style task board, category filters, and statistics
- **Sample expense data** with realistic categories (Groceries, Transport, Dining, Shopping, Utilities, Entertainment)
- **Real-time greeting** that adjusts based on time of day
- **Modal interactions** for viewing expense details
- **Smooth animations** and transitions

## 📱 Features

### Dashboard View
- **Today's Balance Ribbon**: Visual timeline of your spending categories
- **Summary Stats**: Quick metrics on pending, overdue, recorded, and budget status
- **Expense Board**: Kanban board to track expenses through workflows
- **Category Breakdown**: Visual representation of spending by category

### Navigation
- Smooth scrolling navigation
- Mobile hamburger menu
- Responsive sidebar
- Quick access to all sections

### Interactivity
- Click any expense card to view details in a modal
- Filter expenses by category
- Search expenses by name
- State transitions (todo → processing → done)
- Real-time updates

## 🛠️ Technical Stack

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Custom properties (CSS variables), Grid, Flexbox, animations
- **JavaScript**: Vanilla JS (no frameworks) with modular code organization
- **Fonts**: Google Fonts (Space Grotesk, Inter, IBM Plex Mono)
- **Icons**: Inline SVGs for small file size

## 🎨 Design System

The UI uses a cohesive color palette and design tokens:

- **Primary**: Violet (#6C5CE7)
- **Secondary Colors**: Teal, Coral, Amber, Pink, Green (for categories)
- **Typography**: Space Grotesk (headings), Inter (body), IBM Plex Mono (metadata)
- **Spacing**: Consistent 8px grid system
- **Shadows**: Subtle, layered shadows for depth
